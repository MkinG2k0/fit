Фильтр истории (D-02):
- `lib/filterExerciseHistoryForAiFill.ts`: вход `days: Record&lt;string, CalendarDay&gt;`, идентичность упражнения (`name`, optional `catalogExerciseId`), `months` (по умолчанию `AI_FILL_HISTORY_MONTHS`), optional `now` (dayjs).
- Окно: календарные месяцы назад от `now.startOf("day")` — дни с ключами `DD-MM-YYYY` в полуинтервале от `today.subtract(months, "month")` до today включительно (аналогично логике дат в `filterDaysByPeriod`, но месяцами, не «29 дней»).
- Оставить в дне только упражнения, совпадающие с целью: приоритет `catalogExerciseId` если задан у цели и у кандидата; иначе case-insensitive trim name (паттерн `pickExerciseOnDay` / findLastExerciseSession). Дни без совпадений и дни без logged sets (reps&gt;0 или weight&gt;0) отбросить.
- Вернуть `Record&lt;string, CalendarDay&gt;` совместимый с существующим `buildWorkoutLogText` — не дублировать форматтер журнала, переиспользовать его.

Промпты (D-02):
- `lib/buildAiFillPrompts.ts`: отдельные system/user промпты для задачи «предложи подходы на СЕГОДНЯШНЮЮ сессию для этого упражнения». Не ломать существующие `getSystemPrompt` / `buildUserPrompt` панели рекомендаций.
- System: русский силовой тренер; только факты из журнала; без медицины; выход СТРОГО JSON-объект вида `{"sets":[{"weight":number,"reps":number},...]}` без markdown/пояснений вокруг.
- User: имя упражнения, окно `AI_FILL_HISTORY_MONTHS` месяцев, текст журнала из `buildWorkoutLogText`, просьба вернуть разумное число рабочих подходов (например 3–5, по данным; без выдуманных упражнений).

Парсер (D-02):
- `lib/parseAiFillSets.ts`: экспорт `parseAiFillSets(raw: string): { weight: number; reps: number }[]`.
- Надёжно извлекать JSON: trim; если обёрнут в fence/лишний текст — вырезать первый `{...}` или `[...]`; поддержать и объект `{sets:[...]}`, и голый массив.
- Каждый элемент: конечные числа weight/reps ≥ 0 (целые или округлить разумно); отбросить невалидные; если после фильтра массив пуст — бросить понятную ошибку (русский message) или вернуть [] так, чтобы UI мог показать ошибку «не удалось разобрать ответ».
- Не импортировать новые пакеты.
