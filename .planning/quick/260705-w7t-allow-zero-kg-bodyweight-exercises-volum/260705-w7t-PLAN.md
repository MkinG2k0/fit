# Quick Task 260705-w7t: Zero kg for bodyweight exercises

**Goal:** Allow logging 0 kg (pull-ups etc.) and count volume in stats using effective weight 1 when stored weight is 0.

## Approach

Use centralized `calcSetVolumeKg(weight, reps)` → `reps * (weight > 0 ? weight : 1)` instead of magic at each call site. Cleaner than scattered `|| 1` and matches user intent for ring/analytics volume.

## Tasks

1. Add `calcSetVolumeKg` in `src/shared/lib/calcSetVolumeKg.ts`
2. Replace inline `weight * reps` in analytics, calendar rings, exercise card, workout summary
3. Fix `ExerciseSetRow` to show `0` when set has any logged value (reps or weight > 0, or reps > 0 with weight 0)

- Exercise-level bodyweight flag (future)
- Changing maxWeight KPI semantics (still shows actual max kg)
